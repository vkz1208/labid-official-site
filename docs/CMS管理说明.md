# LabID 官网 CMS 管理说明

## 登录

访问 `/admin`。账号、密码和 Session 密钥由服务器环境变量提供：

- `ADMIN_EMAIL`
- `ADMIN_PASSWORD`
- `ADMIN_SESSION_SECRET`

生产环境没有默认账号。首次部署前必须设置以上变量，其中 Session 密钥建议使用至少 32 字节的随机值。

## 首页内容

“首页内容”可以维护：

- 品牌名称、Hero 标题、说明和 CTA；
- 产品区标题、说明和三个核心价值点；
- 案例区标题和说明；
- 联系区文案、电话、邮箱、48 小时提示；
- 备案号与版权所有方。

点击“保存并发布”后，公开官网使用同一数据源立即读取新内容。
编辑字段时，右侧“实时预览”会展示未保存内容的首页效果；预览不会写入数据库。

## 案例管理

每个案例支持学科、团队规模、说明、目标 URL、封面 URL、替代文本、排序值和上下线状态。新增第 4 个及更多案例不需要修改前端代码。

封面可以直接上传 JPG、PNG、WebP 或 AVIF，单张上限 5MB。上传完成后仍需保存案例。文件通过 `/api/media/` 动态媒体路由提供，生产环境必须持久化 `UPLOAD_DIR`；多实例部署建议将上传接口替换为对象存储。

删除案例会永久移除记录，应仅在确认不再需要时执行；临时隐藏请关闭“在官网展示”。

## 咨询线索

所有通过公开表单校验的线索会先写入数据库，再尝试发送邮件。即使 SMTP 暂时失败，线索仍会保存在后台。

状态包括：

- 新线索
- 已联系
- 已关闭

建议运营人员联系客户后及时更新状态。

后台同时显示邮件通知状态与尝试次数。发送失败时可以点击“重新发送”；无论邮件状态如何，已经落库的线索都不会丢失。

## 操作记录

后台会记录登录成功/失败/限流、内容发布、案例增删改、图片上传、线索状态更新和邮件重试。记录不包含管理员密码或 SMTP 密钥。

## 图片

V1 使用可配置图片 URL。生产环境建议把封面上传到对象存储，再将 HTTPS 地址填入 CMS。封面必须填写准确的替代文本，以满足可访问性与图片加载失败场景。
